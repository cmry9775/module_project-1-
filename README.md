## 1. `test4.ipynb` 전처리 및 분석 내용

`test4.ipynb`에서는 모델링의 정확도를 높이기 위해 **외부 공공데이터 연동, 결측치 및 예외 기간 필터링, 기상 데이터 정규화 및 상관관계 분석** 수행

### 공공데이터 수집 및 날짜 복원

* 공공데이터포털을 통해 **공휴일 데이터를 실시간으로 수집**.
* 요일 컬럼 패턴을 분석하여 **정확한 날짜 시퀀스를 복원**

### 특수 이벤트 기간(운영 중단) 데이터 제외

* `'늑구 탈출 사건'`으로 인한 운영 중단 기간인 **2026-04-08 ~ 2026-06-03**의 데이터 **57행**을 제외하여 분석 왜곡 방지

### 기상 피처 정규화(Normalization)

* 모델 학습 효율을 높이기 위해 주요 기상 피처인 **온도(`temperature`), 습도(`humidity`), 강수량(`rain`)**에 정규화 적용

### 피처 간 상관관계 분석

* **공휴일, 주말, 요일별(월~일), 기상 피처(온도, 강수량, 습도)** 간의 상관관계를 산출하여 다중공선성 및 변수 간 연관성 검토.
* 전처리가 완료된 최종 데이터는 **`Oworld_final_processed.csv`** 파일로 저장

## 2. `test5.ipynb` 샌드위치 데이 분석 내용

`test5.ipynb`에서는 공휴일과 주말 사이에 끼인 평일인 **'샌드위치 데이'가 방문객 패턴에 미치는 영향**을 파악하기 위해 추가적인 분석 로직 도입

### 샌드위치 데이 탐지 및 정의

* 공휴일과 주말 사이에 위치한 특정 평일을 **'샌드위치 데이'**로 정의
* 공휴일 데이터를 기반으로 샌드위치 데이를 **자동 탐지하는 로직** 적용

### 특성 융합 및 모델링 연계

* 샌드위치 데이, 공휴일, 주말 등의 요소를 하나의 통합 특성인 **`day_type`** 등으로 융합하여 분석 효율을 높이고 모델링에 반영.

### 데이터 규모 한계에 따른 협의 필요성

* 샌드위치 데이 데이터가 **총 11개**로 적게 도출
* 표본 수가 적어 통계적 유의성을 확보하기에는 다소 한계
